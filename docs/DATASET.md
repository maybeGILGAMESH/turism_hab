# Датасет и права

## Текущий источник

Система не выполняет интернет-поиск. Единственный входной набор — вручную
проверенные фотографии в
`dataset/datasets_clear/khabarovsk_tourism_44/work/khabarovsk_tourism_44` и его
`manifest.csv`. Из 352 записей поставки пользователь оставил 309 файлов; 43
удалённых кадра при импорте автоматически пропускаются.

```powershell
.\collect-data.ps1
```

Команда переносит предыдущие manifest/processed/index в датированный каталог
`.runtime/dataset-archive`, проверяет декодирование и SHA-256, применяет
EXIF-ориентацию и сохраняет нормализованные JPEG. Все 44 объекта связаны через
явный `object_id` из входного manifest, а не через название папки.

## Разбиение и аугментации

Для класса с четырьмя и более оригиналами выделяется по одному исходнику в
`validation` и `test`. При двух-трёх исходниках один выделяется в `test`, чтобы
сохранить максимум реальных ракурсов для индекса. Только `index` дополняется до
12 кадров мягкими детерминированными преобразованиями: небольшой crop/shift,
поворот до 4°, коррекция яркости, контраста, насыщенности и JPEG quality.

Manifest хранит `source_group`, `is_augmented`, `parent_sha256` и
`augmentation`. Родитель и его производные всегда принадлежат одному split.
Итоговая оценка использует leave-one-source-group-out: при проверке оригинала
из кандидатов удаляются он сам и все его производные. После измерения serving
index строится на всех 612 кадрах.

## Ограничения качества

Аугментация учит устойчивости к условиям съёмки, но не создаёт новый ракурс.
Классы 17 и 32 с двумя-тремя оригиналами остаются наиболее рискованными.
Отдельного набора неизвестных объектов в текущей ручной поставке нет, поэтому
FAR 4,85% является proxy по самому похожему неверному классу, а не оценкой на
реальных посторонних фотографиях.

## Права

Входной manifest содержит URL поисковой миниатюры, но не подтверждает автора и
лицензию. Поэтому оригиналы и производные имеют `rights_status=pending_purchase`.
Они разрешены только для локального стенда и исключены из Git/Docker context.
Перед публичным или коммерческим использованием необходимо определить
первоисточник, правообладателя и лицензию, затем сменить статус на `cleared`.

```powershell
python data_pipeline.py export-cleared
```
