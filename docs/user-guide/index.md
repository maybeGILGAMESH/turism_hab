# User Guide

Welcome to the User Guide for the Moscow Metro Cultural Heritage Recognition System.

## How to Use the System

### Basic Usage

1. **Upload an Image**: Take a photo of a metro station or upload an existing image
2. **Select Station**: Choose the metro station name from the dropdown (optional)
3. **Get Recognition**: Click "Recognize" to get AI-powered results
4. **View Results**: See recognized objects with descriptions and confidence scores

### Advanced Features

- **Search by Text**: Use text queries to find specific objects
- **Browse Database**: Explore the complete collection of cultural heritage objects
- **Station Navigation**: Filter objects by specific metro stations
- **Image Comparison**: Compare your photos with database images

## Tips for Best Results

- **Good Lighting**: Ensure the object is well-lit
- **Clear Focus**: Keep the camera steady and focused
- **Multiple Angles**: Try different viewing angles for better recognition
- **Station Context**: Providing station name improves accuracy

## Understanding Results

### Confidence Scores
- **High (0.8-1.0)**: Very confident recognition
- **Medium (0.5-0.8)**: Reasonably confident
- **Low (0.1-0.5)**: Less confident, may need verification

### Object Information
Each recognized object includes:
- Name and description
- Historical context
- Artist/architect information
- Location details
- Related images

## Troubleshooting

### Common Issues

**No recognition results:**
- Try a different angle or lighting
- Ensure the object is clearly visible
- Check if the station is in our database

**Low confidence scores:**
- Improve image quality
- Get closer to the object
- Reduce background clutter

**System errors:**
- Refresh the page
- Check your internet connection
- Try a different browser
