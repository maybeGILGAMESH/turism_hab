# 🏔️ North Caucasus Tourist Attractions Recognition System

AI-платформа для мгновенного распознавания достопримечательностей Северного Кавказа по фотографии. Проект объединяет компьютерное зрение (CLIP), FAISS-поиск и контентную базу, чтобы туристы, музеи и региональные центры могли получать проверенную информацию «в поле».

## 🎯 Основные возможности

- 📸 **Распознавание**: загрузите фото крепости, башенного комплекса или природного объекта и получите описание, координаты и уверенность распознавания
- 🗂️ **Каталог**: свыше 50 объектов в `artifacts_turism/turism.json` с примерами изображений из `dataset/`
- 🧭 **Планировщик маршрутов**: введите координаты — система предложит до 10 ближайших достопримечательностей и построит маршрут
- 👤 **Аккаунты и история**: регистрация/вход, персональная история распознанных изображений
- ⚙️ **Админ-панель**: добавляйте новые объекты и обновляйте контент без переобучения модели
- 📱 **Мобильный клиент**: Expo-приложение с офлайн очередью запросов и личным кабинетом
- 🌐 **REST API**: интеграция с внешними сервисами, чат-ботами и туристическими платформами

## 🏗️ Архитектура

```
Streamlit UI / Static HTML / Expo Mobile
            │
            ▼
       FastAPI backend (app.py)
            │
            ▼
  CLIP ViT-B/16 + FAISS (rag_searcher.py)
            │
            ├── artifacts/db/index.faiss     (векторный индекс)
            └── artifacts_turism/turism.json (каталог объектов)
```

- **Streamlit (`frontend.py`)** — посетительский режим, маршрутный планировщик, личный кабинет с историей, админка и раздел статистики
- **Static HTML (`static/index.html`)** — лёгкая drag & drop форма
- **Expo Mobile (`mobile-app/`)** — офлайн очередь, история запросов, настройки API URL
- **FastAPI (`app.py`)** — обработка загрузок, распознавание, CRUD по объектам, статистика, аутентификация и хранение истории (SQLite `users.db`)
- **RAG ядро (`rag_searcher.py`)** — CLIP embeddings + FAISS kNN + JSON-описания

## 🚀 Быстрый старт

### Требования
- Python 3.11+
- Рекомендуется ≥8 GB RAM
- GPU опционально (для ускорения инференса)

### Установка
   ```bash
git clone <repo>
cd turism
   pip install -r requirements.txt
   ```

### Запуск
```bash
# Backend
python app.py          # http://localhost:8000

# Streamlit UI
streamlit run frontend.py   # http://localhost:8501

# (опционально) статический HTML
python -m http.server 8080  # http://localhost:8080/static/index.html
```

> При первом запуске backend автоматически создаёт файл `users.db` (SQLite) для хранения пользователей и истории распознаваний.

CLI-оркестратор:
   ```bash
python run_system.py   # запускает backend + Streamlit + HTML (есть легаси-брендинг)
```

## 📚 Данные и артефакты

- `artifacts/db/index.faiss`, `index.pkl` — FAISS индекс и метаданные
- `artifacts_turism/turism.json` — каталог достопримечательностей (id, название, местоположение, историческая справка)
- `dataset/NN_Название/ground/*.jpg` — фотобанк (ID синхронизирован с JSON)
- `pool/recognized/` — архив лучших распознаваний (`obj_<id>_dist_<score>_<timestamp>.jpg`)

## 📖 Руководство пользователя

### Посетитель
1. (Опционально) Зарегистрируйтесь или войдите, чтобы сохранять личную историю распознаваний
2. Загрузите изображение (JPG/PNG, ≤10 MB) и получите информацию: `object_id`, уверенность, описание
3. Если объект не найден — система подскажет, как улучшить снимок
4. Используйте блок «Спланировать маршрут»: укажите координаты и получите список ближайших 10 достопримечательностей
5. Просматривайте сохранённую историю распознаваний через Streamlit (изображения доступны по `/uploads/...`)

### Администратор
1. Войдите в аккаунт с ролью `admin`
2. Streamlit → «⚙️ Админ панель»: заполните форму (название, местоположение, описание, изображения)
3. После сохранения обязательно выполните:
   ```bash
   python build_index.py   # регенерация FAISS
   python check_index.py   # проверка индекса и каталога
   ```
4. При необходимости обновите объекты через раздел «✏️ Редактировать» (название, описание, координаты)

### Мобильное приложение (Expo)
     ```bash
cd mobile-app
npm install
expo start
```
- В `App.js` замените `DEFAULT_API_BASE_URL` на IP сервера (например, `http://192.168.0.10:8000`)
- В приложении: ⚙️ Настройки → URL сервера API → сохранить
- Очередь запросов работает офлайн и синхронизируется при появлении сети

## 🔌 REST API

Базовый URL: `http://localhost:8000`

| Endpoint | Method | Описание |
|----------|--------|----------|
| `/api/recognize` | POST | Распознавание изображения (multipart/form-data) |
| `/api/objects` | GET | Каталог объектов с примерами изображений |
| `/api/objects` | POST | Добавление нового объекта (требует Bearer-токен admin) |
| `/api/objects/{id}` | PUT | Обновление названия/описания/локации (admin) |
| `/api/stats` | GET | Статистика по каталогу, датасету, пользователям |
| `/health` | GET | Проверка доступности |
| `/docs`, `/redoc` | GET | Swagger UI / ReDoc |
| `/api/plan-route` | POST | Построение маршрута по координатам (`latitude`, `longitude`, `limit`) |
| `/auth/register` | POST | Регистрация пользователя (`role`: user/admin) |
| `/auth/login` | POST | Получение Bearer-токена |
| `/auth/logout` | POST | Завершение сессии |
| `/auth/me` | GET | Информация о текущем пользователе |
| `/auth/me/recognized` | GET | История распознанных изображений (требуется токен) |

Пример запроса:
```python
import requests

with open("photo.jpg", "rb") as f:
    response = requests.post(
        "http://localhost:8000/api/recognize",
        files={"file": ("photo.jpg", f, "image/jpeg")}
    )
    print(response.json())
```

## 🧠 Технические подробности

- **Модель**: CLIP ViT-B/16 (PyTorch 2.8.0, torchvision 0.23.0)
- **Векторное хранилище**: FAISS cpu 1.12.0 (`k=5`)
- **Порог**: `similarity_threshold = 0.90`; `confidence = max(0, 1 - distance / 0.9)`
- **Производительность**: 0.8–1.2 секунды на CPU; индекс ~40 MB; RAM footprint ~500–600 MB
- **Датасет**: 400+ изображений, >50 объектов (Дагестан, Чечня, Ингушетия, КБР, Карачаево-Черкесия, Ставрополь)
- **Результаты**: успешные распознавания (distance < 0.5) копируются в `pool/recognized`

## 🔐 Эксплуатация и безопасность

- Валидация MIME и размера файла, очистка временных файлов в `finally`
- `POST/PUT /api/objects` пока без защиты ⇒ нужно внедрить auth (JWT/OAuth2) и rate limiting
- Рекомендация: ограничить доступ к админке через VPN или прокси с basic auth
- Логи: стандартный `print` (планируется переход на `logging` с корреляцией запросов)

## 🧰 Кастомизация

- Порог и формула confidence — `app.py`
- Переключение на GPU — установить `faiss-gpu`, задать `device="cuda"`
- Расширение каталога — обновить `turism.json`, синхронизировать `dataset/`, запустить `build_index.py`
- Мультиязычность — добавить поля в JSON, реализовать переключатель в UI
- База данных — мигрировать контент в PostgreSQL/SQLModel, добавить Alembic
- Хранилище — вынести изображения и пул в S3/MinIO, хранить signed URL
- Мониторинг — интеграция с Prometheus/Grafana, Sentry, structured logging

## 🐛 Частые вопросы

| Симптом | Возможная причина | Решение |
|---------|-------------------|---------|
| `RAG searcher not initialized` | Нет `artifacts/db` или `turism.json` | Проверьте пути, права, выполните `build_index.py` |
| Всегда «объект не найден» | distance > 0.90 | Попробуйте другой ракурс/освещение, расширьте фотобанк |
| 500 при `POST /api/objects` | Загружены не изображения | Используйте JPEG/PNG, проверьте типы файлов |
| Streamlit не видит backend | Неверный `API_BASE_URL` | Установите `export API_BASE_URL=http://<ip>:8000` |
| Expo не подключается | Сервер и устройство в разных сетях | Подключите одно Wi-Fi, проверьте IP/Firewall |
