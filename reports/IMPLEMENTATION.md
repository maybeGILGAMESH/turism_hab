Дата проверки: 11 сентября 2026.

- независимый проект `turism_hab`; исходный `turism` не изменялся;
- Python 3.11.16, uv 0.12.12, venv, кэши, Android SDK/AVD и Gradle на диске E;
- каталог из 44 объектов с валидируемой схемой, координатами и источниками;
- импортирован пользовательский очищенный набор: 309 оригиналов, 43 удалённых
  записи поставки пропущены, повреждённых файлов и SHA-дубликатов нет;
- создано 303 мягких index-аугментации; всего 612 записей и 12 index-кадров на
  каждый из 44 классов;
- source groups не пересекают split, проверяемый оригинал и его производные
  исключаются из собственного leave-one-source-out fold;
- FAISS `IndexFlatIP`: 612 нормализованных CLIP-векторов, версии
  catalog/manifest/model зафиксированы;
- OpenAI CLIP ViT-B-16 checkpoint подтверждён SHA-256
  `5806e77cd80f8b59890b7e101eabd078d9fb84e6937f9e85e4ecb61988df416f`;
- FastAPI `/health`: `ready`, `index_ready=true`, `quality_ready=true`;
- Docker Compose: API и Streamlit healthy, распознавание тестовой фотографии
  через Docker API успешно;
- Expo Doctor 18/18, Expo Web export успешен, Android Emulator загрузил экран
  приложения и подключился к `10.0.2.2:8000`;
- Ruff без ошибок, pytest 11/11.

## Метрики

- leave-one-source-out top-1 accuracy: **87,38%**;
- macro recall: **85,20%**;
- proxy false-accept rate: **4,85%**;
- классов с recall не ниже 70%: **39 из 44**;
- классы ниже 70%: 8, 17, 24, 28 и 32.

Метрики рассчитаны на всех 309 оригиналах. Для каждого fold удаляются сам
оригинал и все его аугментации. Затем финальный serving index строится на всём
наборе. Отдельных фотографий неизвестных объектов нет, поэтому false-accept —
proxy по наиболее похожему неверному классу; это явно отражено в metadata.

## Ограничение публичного выпуска

> Обновление 15 сентября 2026: права на все фотографии оформлены, репозиторий
> опубликован публично. Текст ниже описывает состояние на 11 сентября; статусы
> в manifest будут переведены в `cleared` при следующей пересборке индекса.

Все фотографии имеют `rights_status=pending_purchase`: входная поставка хранит
URL поисковых миниатюр, но не подтверждает автора и лицензию. Изображения,
модель, индекс, секреты и runtime исключены из Git. Код готов к размещению в
закрытом GitHub-репозитории; публичный data-export нельзя выпускать до оформления
прав и смены статусов на `cleared`.

`npm audit --omit=dev` для зафиксированного Expo SDK 54 сообщает 23 транзитивных
проблемы (14 moderate, 9 high). Доступное автоматическое исправление требует
несовместимого перехода на Expo 57, поэтому оно не применялось к стенду SDK 54.
Перед публичным мобильным релизом требуется отдельная контролируемая миграция и
повторная проверка Expo Doctor, web и Android.
