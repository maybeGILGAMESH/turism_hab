## 📷 ТРЕК 1: ВИЗУАЛЬНОЕ РАСПОЗНАВАНИЕ ОБЪЕКТОВ КУЛЬТУРЫ

### Задача

Система идентификации объектов культурного наследия московского метро по фотографии. Подумайте в том числе о музеях и туристических сервисах как о возможных потребителях подобного сервиса. Идея простая: пользователь загружает самостоятельно сделанную фотографию произвольного культурного объекта, и в ответ получает описание этого объекта, если он есть в базе.

### Предоставляемые материалы

- Датасет: 27 объектов, от 7 до 20 фото в каждом (бюсты, панно, мозаики из метро)
- Метаданные: id, описание
- Тестовый набор для валидации нужно выделить самостоятельно

### Обязательные компоненты решения

#### 1. Backend API

Реализуйте сервис для работы с системой. Примеры возможных endpoints:

```
POST /api/recognize          # распознавание объекта
GET  /api/objects            # каталог объектов
POST /api/objects            # добавление нового
PUT  /api/objects/{id}       # редактирование
GET  /api/stats              # статистика использования
```

*Это примеры - вы можете спроектировать API по-своему*

#### 2. Пользовательские интерфейсы

- **Для посетителей:** загрузка фото (перекодирование в png) → информация об объекте
- **Для администраторов:** добавление новых идентифицируемых объектов (с переобучением или без переобучения модели)

#### 3. Core функциональность

- Распознавание с confidence score
- Добавление объектов "на лету"
- Обработка случая "объект не найден"

### Технические подсказки

**Модели (у вас есть GPU!):**

- CLIP для zero-shot распознавания
- Fine-tuned ResNet/EfficientNet для классификации
- YOLOv8 для детекции + классификация

**Similarity Search:**

- Faiss GPU для быстрого поиска
- Векторные embeddings изображений
- Косинусная близость для поиска похожих

**Стек разработки:**

- Backend: FastAPI, Flask, Express.js
- Frontend: React, Vue, или даже Streamlit для быстрого прототипа
- БД: PostgreSQL для метаданных, Redis для кэша

### Идеи для развития

- Multi-angle распознавание
- Рекомендации похожих объектов
- AR-режим для мобильных устройств
- Мультиязычность
- QR-коды для музейных табличек

### Метрики успеха

- Точность распознавания > 85%
- Отклик системы < 1 секунды (с GPU должно быть легко!)
- Интуитивный UX для всех типов пользователей
