# Быстрый старт

## Шаг 1: Исправление зависимостей

```bash
cd mobile-app
npx expo install --fix
```

## Шаг 2: Запуск

```bash
npm start
```

## Шаг 3: Подключение с телефона

1. **Установите Expo Go** на телефон (Android/iOS)
2. **Отсканируйте QR-код**, который появится в терминале
3. **Важно**: Убедитесь, что телефон и компьютер в одной Wi-Fi сети

## Если QR-код не работает

1. Откройте Expo Go на телефоне
2. Нажмите "Enter URL manually"
3. Введите: `exp://192.168.0.102:8081`
   (замените IP на IP вашего компьютера)

## Настройка сервера в приложении

1. Откройте приложение
2. Перейдите в "Настройки"
3. Введите URL: `http://192.168.0.102:8000`
   (замените IP на IP вашего компьютера, где запущен backend)

## Проверка IP адреса

```bash
# Linux/Mac
ifconfig | grep "inet "
# или
ip addr show | grep "inet "

# Windows
ipconfig
```

Ищите IP адрес в формате `192.168.x.x` или `10.0.x.x`
