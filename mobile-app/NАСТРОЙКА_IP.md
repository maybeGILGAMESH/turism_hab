# Настройка IP адреса сервера для мобильного приложения

## Важно! 

Мобильное приложение подключается к **FastAPI серверу** (`app.py`), а НЕ к Streamlit или HTML странице!

## Быстрый старт

### 1. Узнайте IP адрес вашего компьютера

**Linux/Mac:**
```bash
hostname -I
# или
ip addr show | grep "inet " | grep -v "127.0.0.1"
```

**Windows:**
```cmd
ipconfig
# Найдите IPv4 адрес (обычно 192.168.x.x)
```

### 2. Запустите FastAPI сервер

```bash
cd /home/ruslan/Downloads/turism
python3 app.py
```

Сервер запустится на `http://0.0.0.0:8000` и будет доступен по IP адресу вашего компьютера.

### 3. Настройте IP в мобильном приложении

**Вариант 1: В коде (по умолчанию)**
- Откройте `mobile-app/App.js`
- Найдите строку: `const DEFAULT_API_BASE_URL = 'http://192.168.0.102:8000';`
- Замените `192.168.0.102` на ваш IP адрес

**Вариант 2: В настройках приложения (рекомендуется)**
- Откройте приложение на телефоне
- Перейдите в раздел "Настройки" (⚙️)
- В поле "URL сервера API" введите: `http://ВАШ_IP:8000`
- Например: `http://192.168.0.102:8000`
- Нажмите "Сохранить настройки"

### 4. Проверьте подключение

- Убедитесь, что телефон и компьютер в одной WiFi сети
- Убедитесь, что FastAPI сервер запущен
- Попробуйте открыть в браузере телефона: `http://ВАШ_IP:8000/api/objects`
- Если видите список объектов - подключение работает!

## Примеры правильных URL:

- ✅ `http://192.168.0.102:8000`
- ✅ `http://192.168.1.100:8000`
- ❌ `http://localhost:8000` (не работает с телефона!)
- ❌ `http://127.0.0.1:8000` (не работает с телефона!)

## Устранение проблем

**Не работает подключение:**
1. Проверьте, что сервер запущен: `python3 app.py`
2. Проверьте, что IP адрес правильный
3. Проверьте, что телефон и компьютер в одной сети WiFi
4. Проверьте файрвол - порт 8000 должен быть открыт

**Ошибка CORS:**
- FastAPI уже настроен с CORS для всех источников
- Если проблема остается, проверьте настройки в `app.py`

Если ваш IP другой, измените его в `App.js` или в настройках приложения.
