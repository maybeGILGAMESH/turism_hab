# Отладка проблемы с распознаванием

## Проблема
Фото загружается, но приложение "крутится" и не распознает объект.

## Возможные причины и решения

### 1. Сервер не запущен или недоступен

**Проверка:**
```bash
# На компьютере проверьте, запущен ли сервер
curl http://localhost:8000/health
# Или откройте в браузере: http://YOUR_IP:8000/health
```

**Решение:**
```bash
cd /home/ruslan/Downloads/turism
python app.py
# или
uvicorn app:app --host 0.0.0.0 --port 8000
```

### 2. Неправильный IP адрес сервера в настройках приложения

**Проверка:**
1. Откройте приложение на телефоне
2. Перейдите в раздел "Настройки"
3. Проверьте URL сервера

**Узнать IP адрес компьютера:**
```bash
# Linux/Mac
ip addr show | grep "inet " | grep -v 127.0.0.1
# или
hostname -I

# Windows
ipconfig
```

**Решение:**
- Обновите URL в настройках приложения на `http://YOUR_IP:8000`
- Убедитесь, что телефон и компьютер в одной сети Wi-Fi

### 3. Запрос зависает (таймаут)

**Что исправлено:**
- ✅ Добавлен таймаут 60 секунд для запросов
- ✅ Добавлено подробное логирование
- ✅ Исправлена проблема с заголовками FormData

**Проверка логов:**
В Metro bundler или Expo Go вы увидите логи:
- `📤 Starting recognition request to: ...` - запрос начат
- `📋 FormData created, sending request...` - данные подготовлены
- `📥 Response received, status: ...` - ответ получен
- `✅ Recognition result: ...` - результат распознавания

Если видите `⏱️ Request timeout`, значит сервер обрабатывает запрос слишком долго.

### 4. RAG searcher не инициализирован на сервере

**Проверка логов сервера:**
При запуске `app.py` должно быть:
```
✅ RAG searcher initialized successfully
```

Если видите:
```
❌ Error initializing RAG searcher: ...
```

**Решение:**
```bash
# Проверьте наличие файлов
ls -la artifacts/db/index.faiss
ls -la artifacts_turism/turism.json

# Если файлов нет, пересоберите индекс
python build_index.py
```

### 5. Проблемы с сетью или файрволом

**Проверка:**
```bash
# На телефоне (если есть доступ к терминалу или используйте браузер)
# Откройте в браузере телефона: http://YOUR_IP:8000/health

# На компьютере проверьте, слушает ли порт 8000
netstat -tulpn | grep 8000
# или
ss -tulpn | grep 8000
```

**Решение:**
- Убедитесь, что файрвол разрешает входящие соединения на порт 8000
- Проверьте, что сервер запущен с `--host 0.0.0.0` (не `127.0.0.1`)

### 6. Изображение слишком большое или неправильного формата

**Что проверяется:**
- Максимальный размер: 10MB
- Форматы: JPG, JPEG, PNG

**Решение:**
- Используйте изображения меньше 10MB
- Конвертируйте в JPG, если нужно

## Дополнительная диагностика

### Включите подробное логирование

В `CameraScreen.js` уже добавлено логирование. Проверьте консоль Metro bundler или React Native Debugger.

### Проверьте ответ сервера

Если запрос доходит до сервера, проверьте логи сервера:
```bash
# В терминале, где запущен app.py, должны быть логи:
# - "Recognition error: ..." при ошибках
# - "✅ Saved well-recognized image to pool: ..." при успехе
```

### Тест API вручную

```bash
# С компьютера проверьте API
curl -X POST http://localhost:8000/api/recognize \
  -F "file=@path/to/test/image.jpg"

# Или используйте Python
python -c "
import requests
with open('test_image.jpg', 'rb') as f:
    response = requests.post('http://localhost:8000/api/recognize', files={'file': f})
    print(response.json())
"
```
