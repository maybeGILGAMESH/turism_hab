# Инструкция по установке и запуску мобильного приложения

## Факультет Искусственного Интеллекта РУДН

## Шаг 1: Установка зависимостей

```bash
cd mobile-app
npm install
```

## Шаг 2: Исправление версий зависимостей

Expo автоматически проверит и предложит исправить версии. Выполните:

```bash
npx expo install --fix
```

Или установите правильные версии вручную:

```bash
npx expo install react-native@0.72.10 @react-native-async-storage/async-storage@1.18.2 @react-native-community/netinfo@9.3.10
```

## Шаг 3: Запуск приложения

### Вариант 1: Через Expo Go на телефоне (рекомендуется)

1. **Установите Expo Go на телефон:**
   - Android: [Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent)
   - iOS: [App Store](https://apps.apple.com/app/expo-go/id982107779)

2. **Запустите сервер разработки:**
   ```bash
   npm start
   ```
   
3. **Отсканируйте QR-код:**
   - **Android**: Откройте приложение Expo Go и нажмите "Scan QR code"
   - **iOS**: Откройте камеру (встроенное приложение) и наведите на QR-код
   
4. **Важно для подключения:**
   - Убедитесь, что телефон и компьютер в одной Wi-Fi сети
   - Если QR-код не работает, можно подключиться вручную:
     - В Expo Go нажмите "Enter URL manually"
     - Введите: `exp://192.168.0.102:8081` (замените IP на IP вашего компьютера)

### Вариант 2: Через эмулятор Android

Если у вас установлен Android Studio:

1. Запустите Android эмулятор
2. Выполните:
   ```bash
   npm start
   ```
3. Нажмите `a` для открытия в Android эмуляторе

### Вариант 3: Через веб-браузер (для тестирования)

```bash
npm start
# Нажмите 'w' для открытия в браузере
```

Но сначала установите зависимости для веба:
```bash
npx expo install react-native-web react-dom @expo/webpack-config
```

## Шаг 4: Настройка URL сервера

1. Откройте приложение на телефоне
2. Перейдите в раздел "Настройки"
3. Введите URL вашего сервера:
   - Для локальной сети: `http://192.168.0.102:8000` (замените на IP вашего компьютера)
   - Для проверки IP выполните:
     - Linux/Mac: `ifconfig` или `ip addr`
     - Windows: `ipconfig`

## Решение проблем

### Проблема: "Failed to resolve the Android SDK path"

Это нормально, если вы используете Expo Go на телефоне. Android SDK нужен только для эмулятора.

### Проблема: "No compatible apps connected"

1. Убедитесь, что Expo Go установлен на телефоне
2. Проверьте, что телефон и компьютер в одной Wi-Fi сети
3. Попробуйте подключиться вручную через IP адрес

### Проблема: QR-код не сканируется

1. Убедитесь, что телефон и компьютер в одной сети
2. Попробуйте подключиться вручную:
   - В Expo Go: "Enter URL manually"
   - Введите: `exp://YOUR_COMPUTER_IP:8081`
3. Проверьте, что порт 8081 не заблокирован firewall

### Проблема: Несовместимые версии зависимостей

```bash
npx expo install --fix
```

Это автоматически установит правильные версии.

### Проблема: Приложение не подключается к серверу

1. Проверьте, что сервер запущен на компьютере
2. Убедитесь, что в настройках приложения указан правильный IP адрес
3. Проверьте firewall - порт 8000 должен быть открыт
4. Попробуйте подключиться с телефона через браузер: `http://YOUR_IP:8000`

## Полезные команды

- `npm start` - запустить сервер разработки
- `npx expo start --clear` - запустить с очисткой кэша
- `r` - перезагрузить приложение
- `j` - открыть отладчик
- `m` - показать меню разработчика
