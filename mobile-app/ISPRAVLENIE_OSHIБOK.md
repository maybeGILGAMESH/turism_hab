# Исправление ошибки "Failed to download remote update"

## Проблема

Ошибка появляется когда Expo Go не может подключиться к Metro bundler на компьютере.

## Решения (по порядку)

### Решение 1: Использовать LAN режим (рекомендуется)

Запустите приложение с явным указанием LAN режима:

```bash
npm run start
# или
expo start --lan
```

Затем:
1. Убедитесь, что телефон и компьютер в **одной WiFi сети**
2. Отсканируйте QR код или введите URL вручную в Expo Go

### Решение 2: Использовать Tunnel режим

Если LAN не работает, используйте tunnel (работает через интернет):

```bash
npm run start:tunnel
# или
expo start --tunnel
```

**Примечание:** Tunnel режим медленнее, но работает даже если устройства в разных сетях.

### Решение 3: Ввести URL вручную

Если QR код не работает:

1. Посмотрите в терминале URL вида: `exp://192.168.0.102:8081`
2. В Expo Go нажмите "Enter URL manually"
3. Введите этот URL

### Решение 4: Проверить файрвол

Убедитесь, что порт 8081 открыт:

```bash
# Linux
sudo ufw allow 8081
# или
sudo iptables -A INPUT -p tcp --dport 8081 -j ACCEPT
```

### Решение 5: Проверить сеть

Убедитесь, что:
- ✅ Телефон и компьютер в одной WiFi сети
- ✅ IP адрес правильный (проверьте: `hostname -I`)
- ✅ Metro bundler запущен (видите QR код в терминале)

### Решение 6: Использовать веб-версию для тестирования

Если ничего не помогает, можно протестировать в браузере:

```bash
npm run web
# или
expo start --web
```

Откройте `http://localhost:19006` в браузере.

## Быстрая проверка

1. Запустите: `npm start`
2. В терминале должен появиться QR код
3. Убедитесь, что видите URL вида: `exp://192.168.0.102:8081`
4. Проверьте, что IP совпадает с IP вашего компьютера
5. Откройте Expo Go и отсканируйте QR код

## Дополнительная информация

- **LAN режим** (`--lan`) - быстрый, но требует одну сеть
- **Tunnel режим** (`--tunnel`) - медленнее, но работает везде
- **Localhost режим** (по умолчанию) - только для эмулятора

Если проблема остаётся, попробуйте перезапустить:
1. Metro bundler (Ctrl+C, затем `npm start`)
2. Expo Go на телефоне (закрыть и открыть заново)
3. WiFi на обоих устройствах
