# Мобильное приложение для распознавания туристических достопримечательностей Северного Кавказа

## Факультет Искусственного Интеллекта РУДН

Мобильное приложение с поддержкой офлайн режима, очереди запросов и личного кабинета.

## Возможности

- 📸 **Распознавание достопримечательностей** - загрузка фото из галереи или с камеры
- 📚 **Личный кабинет** - история всех распознанных объектов
- ⏳ **Очередь запросов** - автоматическое сохранение запросов в офлайн режиме
- 🔄 **Синхронизация** - автоматическая отправка запросов при появлении интернета
- ⚙️ **Настройки** - настройка URL сервера

## Установка

### Требования

- Node.js 16+
- npm или yarn
- Expo CLI (`npm install -g expo-cli`)
- Для iOS: Xcode (только на macOS)
- Для Android: Android Studio

### Шаги установки

1. Установите зависимости:
```bash
npm install
```

2. Запустите приложение:
```bash
npm start
```

3. Отсканируйте QR-код в приложении Expo Go на вашем телефоне, или нажмите:
   - `a` для Android эмулятора
   - `i` для iOS симулятора

## Настройка

### ⚠️ ОБЯЗАТЕЛЬНО: Настройка IP адреса сервера

IP адрес нужно настроить в **двух местах**:

#### 1. В коде (для разработки)

Откройте `App.js` и найдите строку:
```javascript
const DEFAULT_API_BASE_URL = 'http://192.168.0.102:8000';
```
**Замените `192.168.0.102` на IP вашего компьютера!**

#### 2. В приложении (через настройки)

1. Откройте приложение на телефоне
2. Перейдите в раздел **"Настройки"** (⚙️)
3. В поле "URL сервера API" введите: `http://ВАШ_IP:8000`
4. Нажмите **"Сохранить настройки"**

**Как узнать IP адрес:**
- Windows: `ipconfig`
- macOS/Linux: `ifconfig` или `ip addr`

**Важно:** 
- Убедитесь, что телефон и компьютер в **одной Wi-Fi сети**
- Backend должен быть запущен (`python app.py`)
- Firewall должен разрешать подключения на порт 8000

📖 Подробная инструкция: см. `KONFIGURATSIYA.md`

## Особенности офлайн режима

- Когда нет интернета, запросы автоматически сохраняются в очередь
- При появлении интернета очередь автоматически обрабатывается
- Все результаты сохраняются в личном кабинете
- Максимум 3 попытки для каждого запроса

## Структура проекта

```

├── App.js                 # Главный компонент приложения
├── screens/               # Экраны приложения
│   ├── CameraScreen.js    # Распознавание изображений
│   ├── HistoryScreen.js   # Личный кабинет
│   ├── QueueScreen.js     # Очередь запросов
│   └── SettingsScreen.js  # Настройки
├── services/              # Сервисы
│   ├── RequestQueue.js    # Управление очередью запросов
│   └── StorageService.js  # Локальное хранилище
└── package.json           # Зависимости проекта
```
