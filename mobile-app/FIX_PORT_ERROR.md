# Исправление ошибки 403 Forbidden - неправильный порт

## Проблема

В настройках приложения указан **неправильный порт**:
- ❌ Используется: `http://192.168.78.154:8501` (Streamlit)
- ✅ Нужно: `http://192.168.78.154:8000` (FastAPI)

## Объяснение

В системе есть два сервера:

1. **FastAPI (порт 8000)** - API сервер с endpoint `/api/recognize`
   - Это тот, который нужен для мобильного приложения
   - Обрабатывает распознавание изображений

2. **Streamlit (порт 8501)** - Веб-интерфейс для браузера
   - Это веб-приложение для просмотра через браузер
   - Не имеет API endpoints для мобильного приложения

## Решение

### Шаг 1: Откройте настройки в мобильном приложении

1. Откройте приложение на телефоне
2. Перейдите в раздел **"Настройки"** (⚙️ вкладка внизу)

### Шаг 2: Измените URL сервера

1. Найдите поле **"URL сервера"**
2. Измените значение с:
   ```
   http://192.168.78.154:8501
   ```
   на:
   ```
   http://192.168.78.154:8000
   ```
3. Сохраните настройки

### Шаг 3: Проверьте, что FastAPI сервер работает

На компьютере проверьте:
```bash
curl http://localhost:8000/health
```

Должен вернуться JSON:
```json
{
  "status": "healthy",
  "rag_searcher": "initialized",
  "timestamp": "..."
}
```

### Шаг 4: Проверьте доступность с телефона

Откройте в браузере телефона:
```
http://192.168.78.154:8000/health
```

Должен вернуться тот же JSON ответ.

### Шаг 5: Попробуйте распознать фото снова

После изменения URL на порт 8000, попробуйте распознать фото снова. Теперь должно работать! ✅

## Проверка портов

Для проверки, какие серверы запущены:
```bash
netstat -tulpn | grep -E ":(8000|8501)"
```

Ожидаемый результат:
- `0.0.0.0:8000` - Python3 (FastAPI) ✅
- `0.0.0.0:8501` - Streamlit (веб-интерфейс) ✅

## Резюме

- **Для мобильного приложения**: используйте порт **8000** (FastAPI)
- **Для браузера**: используйте порт **8501** (Streamlit) или порт **8000** (FastAPI web interface)

## После исправления

В логах Metro bundler вы должны увидеть:
```
✅ Server is healthy and reachable
📥 Response received, status: 200
✅ Recognition result: ...
```

Вместо ошибки 403! 🎉
