# Инструкция: Как изменить порт с 8501 на 8000

## Проблема
В логах видно, что приложение всё ещё обращается к порту **8501** вместо **8000**.

## Решение (пошаговая инструкция)

### Шаг 1: Откройте настройки в приложении

1. Откройте приложение на телефоне
2. Перейдите во вкладку **"Настройки"** (иконка ⚙️ внизу экрана)

### Шаг 2: Измените URL

1. Найдите поле **"URL сервера API"**
2. Если там указано:
   ```
   http://192.168.78.154:8501
   ```
   или
   ```
   http://192.168.0.102:8501
   ```

3. **Измените на:**
   ```
   http://192.168.78.154:8000
   ```
   (используйте правильный IP адрес вашего компьютера)

### Шаг 3: Сохраните настройки

1. Нажмите кнопку **"Сохранить настройки"**
2. Если вы ввели порт 8501, приложение автоматически предупредит вас и предложит исправить на 8000
3. Нажмите **"Исправить автоматически"** если появится предупреждение

### Шаг 4: Перезапустите приложение

1. Полностью закройте приложение (смахните из списка запущенных приложений)
2. Откройте приложение снова
3. Или в Metro bundler нажмите `R` дважды для перезагрузки

### Шаг 5: Проверьте логи

После перезапуска в логах Metro bundler вы должны увидеть:
```
🔧 Loading API URL from settings: http://192.168.78.154:8000
✅ API URL loaded: http://192.168.78.154:8000
```

Вместо порта 8501!

### Шаг 6: Попробуйте распознать фото

После изменения порта на 8000, попробуйте распознать фото снова. Теперь должно работать! ✅

## Если настройки не сохраняются

### Вариант 1: Очистить данные приложения (Android)
1. Настройки → Приложения → Expo Go (или ваше приложение)
2. Хранилище → Очистить данные
3. Откройте приложение снова

### Вариант 2: Переустановить приложение
Удалите и установите приложение заново

## Проверка

После изменения настройки, в логах при следующем запросе должно быть:
```
📤 Starting recognition request to: http://192.168.78.154:8000/api/recognize
```

Вместо:
```
📤 Starting recognition request to: http://192.168.78.154:8501/api/recognize
```

## Автоматическое исправление

Теперь в настройках добавлена проверка:
- Если вы введёте порт 8501, приложение автоматически предупредит вас
- Вы можете нажать "Исправить автоматически", чтобы изменить порт на 8000

## Важно

- **Порт 8000** = FastAPI сервер (для мобильного приложения) ✅
- **Порт 8501** = Streamlit веб-интерфейс (для браузера) ❌

Для мобильного приложения **обязательно** используйте порт **8000**!
