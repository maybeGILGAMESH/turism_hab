# 🔧 Конфигурация IP адреса сервера

## Важно: Настройка IP адреса обязательна!

Приложение должно знать, куда отправлять запросы на распознавание. IP адрес настраивается в **двух местах**:

## 1️⃣ В коде (для разработки)

Откройте файл `App.js` и найдите строку:

```javascript
const DEFAULT_API_BASE_URL = 'http://192.168.0.102:8000';
```

**Замените `192.168.0.102` на IP адрес вашего компьютера**, где запущен backend сервер.

### Как узнать IP адрес:

**Linux/Mac:**
```bash
ifconfig | grep "inet "
# или
ip addr show | grep "inet "
```

**Windows:**
```bash
ipconfig
```

Ищите IP адрес в формате `192.168.x.x` или `10.0.x.x` (это локальный IP в вашей сети)

## 2️⃣ В приложении (через настройки)

После запуска приложения:

1. Откройте приложение на телефоне
2. Перейдите во вкладку **"Настройки"** (⚙️)
3. В поле **"URL сервера API"** введите:
   ```
   http://ВАШ_IP:8000
   ```
   Например: `http://192.168.0.102:8000`
4. Нажмите **"Сохранить настройки"**

## ⚠️ Важные моменты:

1. **IP адрес должен быть доступен с телефона:**
   - Убедитесь, что телефон и компьютер в **одной Wi-Fi сети**
   - Если используете разные сети, IP не будет работать

2. **Backend должен быть запущен:**
   ```bash
   # В папке проекта
   python app.py
   # или
   uvicorn app:app --host 0.0.0.0 --port 8000
   ```

3. **Firewall должен разрешать подключения:**
   - На Linux: `sudo ufw allow 8000`
   - На Windows: разрешите порт 8000 в настройках Firewall

4. **Проверка работы:**
   - Откройте на телефоне в браузере: `http://ВАШ_IP:8000`
   - Должна открыться страница API с информацией о версии

## 📝 Пример полной настройки:

1. **Узнать IP компьютера:**
   ```bash
   $ ifconfig
   wlan0: flags=4163<UP,BROADCAST,RUNNING,MULTICAST>  mtu 1500
           inet 192.168.0.102  netmask 255.255.255.0  ...
   ```
   IP: `192.168.0.102`

2. **Запустить backend:**
   ```bash
   cd /home/ruslan/Downloads/turism
   python app.py
   ```

3. **В App.js установить:**
   ```javascript
   const DEFAULT_API_BASE_URL = 'http://192.168.0.102:8000';
   ```

4. **В приложении (настройки) установить:**
   ```
   http://192.168.0.102:8000
   ```

## 🔄 Если IP изменился:

Если IP адрес компьютера изменился (например, при переподключении к Wi-Fi):

1. Узнайте новый IP
2. Обновите в `App.js` (опционально, для разработки)
3. **Обязательно** обновите в настройках приложения

## 💡 Альтернативный вариант (для продакшена):

```
http://your-server.com:8000
```

или

```
https://your-server.com
```
