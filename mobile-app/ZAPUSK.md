# Инструкция по запуску мобильного приложения

## Быстрый старт

### 1. Убедитесь, что FastAPI сервер запущен

В отдельном терминале:
```bash
cd /home/ruslan/Downloads/turism
python3 app.py
```

Сервер должен быть доступен на `http://192.168.0.102:8000`

### 2. Запустите мобильное приложение

```bash
cd mobile-app
npm start
```

### 3. Подключите телефон

**Вариант A: Через Expo Go (рекомендуется для тестирования)**

1. Установите **Expo Go** на телефон:
   - Android: [Google Play](https://play.google.com/store/apps/details?id=host.exp.exponent)
   - iOS: [App Store](https://apps.apple.com/app/expo-go/id982107779)

2. Убедитесь, что телефон и компьютер в одной WiFi сети

3. Отсканируйте QR код, который появится в терминале после `npm start`

4. Приложение откроется в Expo Go

**Вариант B: Через Android эмулятор**

1. Установите Android Studio и Android SDK
2. Настройте `ANDROID_HOME`:
   ```bash
   export ANDROID_HOME=$HOME/Android/Sdk
   export PATH=$PATH:$ANDROID_HOME/emulator
   export PATH=$PATH:$ANDROID_HOME/platform-tools
   ```
3. Запустите эмулятор
4. В терминале с `npm start` нажмите `a` для открытия на Android

### 4. Настройте IP адрес сервера

После открытия приложения:

1. Перейдите в раздел **"Настройки"** (⚙️)
2. В поле **"URL сервера API"** введите: `http://192.168.0.102:8000`
3. Нажмите **"Сохранить настройки"**

### 5. Проверьте подключение

1. Откройте раздел **"Распознавание"** (📸)
2. Выберите изображение из галереи
3. Нажмите **"Распознать"**
4. Если видите результат - всё работает! ✅

## Устранение проблем

**QR код не открывается:**
- Убедитесь, что телефон и компьютер в одной WiFi сети
- Проверьте, что порт 8081 не заблокирован файрволом
- Попробуйте ввести URL вручную в Expo Go: `exp://192.168.0.102:8081`

**Не подключается к серверу:**
- Проверьте, что FastAPI сервер запущен (`python3 app.py`)
- Проверьте IP адрес: `hostname -I`
- Убедитесь, что в настройках приложения указан правильный IP: `http://ВАШ_IP:8000`
- Проверьте, что телефон и компьютер в одной сети

**Ошибка "spawn adb ENOENT":**
- Это нормально, если используете Expo Go на телефоне
- Не нужно для работы через Expo Go
- Нужно только если используете Android эмулятор

## Команды для разработки

- `npm start` - запустить Metro bundler
- `r` - перезагрузить приложение
- `m` - открыть меню разработчика
- `j` - открыть debugger
- `a` - открыть на Android эмуляторе (если настроен)
- `w` - открыть в веб-браузере
- `Ctrl+C` - остановить сервер
